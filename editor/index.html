    Artist dots

    A larger dot that stands for an artist and opens their own room, such as a smaller gallery built with temporary walls. Numbered A1, A2… separately from the artworks. If the room cannot be opened, tapping it shows the dot’s own details instead, so fill it in like an artwork.

      Drag an artwork to position it. Use arrow keys to nudge it.

      Photo tray

      Colour palette

      In a show with several artists, each artist takes the next colour in this list, so all of one artist’s works match. With a single artist, each artwork takes the next colour. The list starts again from the top when it runs out. An artwork keeps its own colour only if you set one for it.

        Room library folder
        New rooms are added automatically from the folder next to this page when it opens: put the SVGs there with an index.json listing their file names, e.g. ["P152.svg","Main gallery.svg"]. Opened straight from your computer, the browser cannot read folders by itself, so use “Choose a rooms folder”. Rooms you delete stay deleted until you check the folder again.
        Floorplanner link
        The file name or address of your Floorplanner page, relative to this page. “Edit in Floorplanner” opens it in a new tab.

          Exhibitions

          Exhibition data is saved in this browser as you edit, and will persist after closing the browser. Multiple exhibitions can be stored and returned.

          Important exhibition data should be saved to your computer. Export each exhibition regularly to preserve progress. Manually clearing browser data removes exhibition progress, and some browsers automatically clear browser data if you have not visited the page after some time.
